# Content Guide

How to change what the site *says and shows* without writing React. This is the
guide for hosts, editors, and anyone forking NatureHouse for their own property.

All paths below are inside `web/`.

---

## 1. Listing facts — `lib/data.ts`

A single TypeScript file of plain constants. Edit values in place.

| Constant | Controls |
| --- | --- |
| `SITE` | Name, tagline, pitch, rating, guest/bed/bath counts, Airbnb URL, approximate map coordinates. |
| `HIGHLIGHTS` | The three cards under the hero. |
| `BEDROOMS` | The sleeping-arrangement cards. |
| `AMENITY_GROUPS` | The grouped amenities index. |
| `DRIVE_TIMES` | The location timeline (place + minutes). |
| `RATING_BREAKDOWN` | The category rating bars. |
| `REVIEWS` | The guest quotes shown on the landing page. |
| `HOST` | Host name, years, response time, bio. |
| `HOUSE_RULES` | The footer rules list. |

> Changing the map pin: set `SITE.approxLat` / `SITE.approxLng`. Keep it
> **approximate** — the site intentionally never shows the exact address.

## 2. The concierge's knowledge — `content/knowledge/*.md`

These markdown files ARE the chatbot's brain. It is instructed to answer **only**
from them. To teach it something new, edit or add a file here.

- Files load in **filename order** (`01-…`, `02-…`), so prefix new files to place them.
- Write plain, factual markdown. Headings and bullet lists work well.
- Keep it truthful; the bot is told to defer to the host for anything not covered
  (pricing, live availability, exact address).

Current files: `01-house`, `02-logistics`, `03-amenities`, `04-area`,
`05-faq`, `06-reviews`.

> After editing, **restart the dev server** — the knowledge base is cached per
> process (see `lib/knowledge.ts`).

## 3. Guidebook articles — `content/guidebook/*.md`

One file per article. Each needs frontmatter:

```markdown
---
title: Getting Here & Settling In
excerpt: One-sentence teaser shown on the card and at the top of the article.
category: Essentials        # grouping label (free text)
order: 1                    # sort order in the index (lower = first)
image: /media/gallery/exterior-01.svg   # hero image (path under public/)
readTime: 3 min
---

## Your first heading
Markdown body goes here...
```

Add a file → it automatically appears in the guidebook index and gets its own
page at `/guidebook/<filename>`. No code changes needed. The same files are also
folded into the concierge's knowledge.

## 4. Photos & drone video — `public/media/` + `lib/media.ts`

Two steps:

1. **Drop files** into `public/media/`:
   - Drone hero: `public/media/drone-hero.mp4` (muted, loops, ~15–40s).
   - Photos: `public/media/gallery/your-photo.jpg` (jpg/png/webp).
2. **Register them** in `lib/media.ts`:

```ts
{
  id: "living-01",
  type: "image",                 // or "video"
  src: "/media/gallery/living-01.jpg",
  poster: "/media/gallery/living-01.jpg", // videos only: a still frame
  category: "Living",            // one of GALLERY_CATEGORIES
  caption: "Living room with the swing chair",
  span: "wide",                  // optional: "big" | "wide" | "tall"
}
```

`span` controls the editorial grid emphasis. `HERO_VIDEO` at the top of the file
sets the hero background. Categories are listed in `GALLERY_CATEGORIES` (add one
there if you need a new filter tab).

The shipped `.svg` files are placeholders generated by
`scripts/gen-placeholders.mjs` (`node scripts/gen-placeholders.mjs`). Delete them
once you have real media.

## 5. Design tokens — `tailwind.config.ts` + `app/globals.css`

Colors (`paper`, `forest`, `moss`, `amber`, …), fonts, and reusable class
recipes live here. See [../DESIGN.md](../DESIGN.md) for the intent behind them.

## Forking for your own property — checklist

- [ ] `lib/data.ts` — replace every fact with yours.
- [ ] `content/knowledge/*.md` — rewrite the knowledge base.
- [ ] `content/guidebook/*.md` — write your own local guides.
- [ ] `public/media/` — replace placeholders with your photos + drone video, update `lib/media.ts`.
- [ ] `app/layout.tsx` / `README` — update site name and metadata.
- [ ] `SITE.approxLat/Lng` and `SITE.airbnbUrl`.
- [ ] Update the `LICENSE` content note if you relicense.
